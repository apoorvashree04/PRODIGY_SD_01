# Temperature Converter App

A modern GUI-based temperature converter built using **Python** and **CustomTkinter**.
This app allows users to convert temperatures between **Celsius, Fahrenheit, and Kelvin** using a clean and interactive interface.

---

##  Features

* Modern Dark UI
* Convert between Celsius, Fahrenheit, Kelvin
* Clean and simple interface
* Theme toggle (Dark/Light)
* Input validation
